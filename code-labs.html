01 / QISKIT LOCAL SIMULATOR

Quantum circuits: Bell → Grover → QPE

This repository uses Qiskit with the native Aer simulator.No cloud quantum platform account or API token is required to run the following three examples; first-time installation requires the ability to obtain dependencies from the Python package source. The project declares support for Python 3.10–3.13.

Run in a separate directory
git clone https://github.com/ShundaZhang/quantum-computing-python-samples.git
cd quantum-computing-python-samples
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python examples/02_bell_entanglement.py
python examples/06_grover_search.py
python examples/07_phase_estimation.py
Windows PowerShell available .venv\Scripts\Activate.ps1 Activate the virtual environment.

02 / PURE PYTHON TOY CRYPTO

Lattices and LWE: see where the hardness lies

This set of experiments only requires Python 3.10+, no third-party packages are needed. It lets you see grid, noise, decryption and brute-force search with very small parameters; then fall back to the ML-KEM / ML-DSA standard.

Run in another independent directory

03 / CONNECT BACK TO SECURITY

From toy models to security decisions

Quantum side

Bell explains measurement and entanglement, Grover explains structureless search acceleration, and QPE builds building block intuition for Shor's period search.

→
Cryptography side

Toy LWE explains the noise problem and parameter trade-offs; it is not an implementation of ML-KEM. Real migration still requires reading standards, selecting mature libraries, and doing protocol verification.

→
System side

Include KEM, signature, TLS, certificate, firmware and remote attestation into the asset list; sort by confidentiality period and migration cost.

Experimental boundaries

The cryptography and quantum codes of both repositories are used for teaching. The implementation of lattice cryptography with minimal parameters, fixed seeds, brute force search, and lack of constant time and side channel protection cannot protect real data; Qiskit simulation results cannot represent the attack capabilities of physical hardware.
