01 / QISKIT LOCAL SIMULATOR

量子线路：Bell → Grover → QPE

这个仓库使用 Qiskit 与本地 Aer 模拟器。运行以下三个示例不需要云端量子平台账号或 API token；首次安装需要能从 Python 包源获取依赖。项目声明支持 Python 3.10–3.13。

在独立目录中运行
git clone https://github.com/ShundaZhang/quantum-computing-python-samples.git
cd quantum-computing-python-samples
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python examples/02_bell_entanglement.py
python examples/06_grover_search.py
python examples/07_phase_estimation.py
Windows PowerShell 可用 .venv\Scripts\Activate.ps1 激活虚拟环境。

实验边界
