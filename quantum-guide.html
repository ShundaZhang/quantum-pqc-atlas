01 / THE MINIMUM MODEL

Start with four essentials

States and measurement

Classic bits are 0 or 1. A single qubit can be written as α|0⟩ + β|1⟩, where |α|² + |β|² = 1. When measured in the 0/1 basis, only one classical result is obtained: the probability of 0 is |α|² and the probability of 1 is |β|².

Phase and interference

Amplitudes can be complex numbers; looking at only one measurement probability will miss the phase. The gate operation will add or cancel the amplitudes of different paths. This interference is the key to the advantage of the algorithm and cannot be understood as "reading out all the answers at once."

Gates and circuits

X is similar to flipping; H turns |0⟩ into (|0⟩ + |1⟩)/√2; CX flips the target bit when the control bit is 1. The lines describe the sequence of gates, and repeated measurements are required to estimate the resulting distribution.

Engineering scale

Reliable logical qubits in algorithms are different from noisy physical qubits. Being able to run a two-qubit experiment does not infer that a machine is equipped to attack existing RSA or ECC.

Analogy for x86/Arm engineers: Think of the quantum circuit as a set of reversible transformations acting on the state vector, and finally retrieve the classical data through measurement. It does not observe intermediate states at any time like reading a register.

03 / ALGORITHM FIELD NOTES

Shor: from modular periods to factors

Shor reduces integer factorization to finding the multiplicative order r: the smallest positive integer for which aʳ ≡ 1 mod N. First handle easy classical cases, choose a strictly between 1 and N and compute gcd(a,N). A nontrivial gcd already factors N; otherwise a is invertible and the quantum stage can estimate its order. The target is polynomial scaling in the bit length log₂N, not constant-time factoring.

Why a period can reveal factors

If r is even, let x = a^(r/2) mod N. x² − 1 = (x−1)(x+1) ≡ 0 mod N. If x ≠ ±1 mod N, try gcd(x−1,N) and gcd(x+1,N).

For N=15 and a=2, powers repeat as 1,2,4,8,1,…; r=4 gives x=4 and factors gcd(3,15)=3, gcd(5,15)=5. An odd r or a trivial half-power can make this attempt fail; retry with another a. Every output must be checked as a nontrivial factor. ECC is threatened by Shor’s related discrete-logarithm algorithm, not by factoring the elliptic-curve modulus.

The quantum part: modular multiplication and phase estimation

|0⟩^t |1⟩ → (1/√Q) Σₓ |x⟩ |aˣ mod N⟩, Q=2ᵗ Eigenphases of modular multiplication: k/r, k=0,…,r−1 After inverse QFT and measurement: c/Q ≈ k/r

Hadamards create the counting-register superposition. Controlled powers U^(2^j) compute modular exponentiation coherently; repeated squaring supplies the classical constants for those powers, but the modular arithmetic itself must be implemented reversibly. The work state |1⟩ is a superposition of modular-multiplication eigenstates, whose eigenphases are k/r. Inverse QFT turns this periodic phase structure into peaks in the counting register. It does not read every modular power as a classical list.

Choose enough counting precision, commonly Q of order N² for the textbook reduction. Continued fractions of c/Q produce a candidate denominator. If k and r have a common factor, that denominator may be only a divisor of r; k=0 gives no order information. Check aʳ mod N, combine or repeat samples as appropriate, and then perform the factor test. Peaks are approximate when Q is not divisible by r.

Why elliptic-curve keys are also affected

For a prime-order group with generator P and public point Q=dP, the discrete-logarithm version coherently evaluates aP+bQ, with a,b taken modulo the group order ℓ. Inputs shifted by (−dt,t) produce the same group element. Fourier sampling extracts a relation between two measured frequencies, rather than factoring a field modulus.

Q = dP; f(a,b) = aP + bQ = (a+bd)P Fourier samples (u,v) satisfy v = d·u (mod ℓ). For u ≠ 0 in this prime-order group: d = v·u⁻¹ mod ℓ.

This is a conceptual hidden-subgroup view: reversible group arithmetic, suitable registers and Fourier operations still have to be implemented. Finite-field Diffie–Hellman has an analogous discrete-logarithm formulation.

A cryptographically relevant attack also needs fault-tolerant logical qubits, reversible modular arithmetic, error correction and a large gate budget. This worked example is not a circuit execution, benchmark, or evidence that present hardware can factor RSA keys.

04 / ALGORITHM FIELD NOTES

Grover: phase marking becomes amplitude amplification

Grover searches N candidates using a reversible predicate f(x) that marks M acceptable solutions. Preparing an address superposition does not make a classical database freely quantum-accessible: the predicate, data access and reversible computation all count. The quantum advantage is O(√(N/M)) oracle queries under the specified model, rather than the classical O(N/M) search cost.

U_f|x⟩|b⟩ = |x⟩|b ⊕ f(x)⟩ With |b⟩ = |−⟩, phase kickback gives O_f|x⟩ = (−1)^f(x)|x⟩. D = 2|s⟩⟨s| − I; each amplitude αₓ becomes 2·mean(α) − αₓ.

The oracle can test a candidate without knowing the solution in advance. For key search, a reversible cipher computes a known plaintext/ciphertext check, phase-marks matching keys, then uncomputes temporary work registers. Multiple pairs may be needed to identify the intended key. A hand-written oracle that simply marks a known answer illustrates interference but does not implement this cryptanalytic workload.

What this means for cryptography

An ideal unique-solution search of a b-bit key has N=2ᵇ and roughly 2^(b/2) query scaling. That is not a wall-clock prediction or a complete security estimate: oracle gate count, circuit depth, quantum memory, parallelization and fault tolerance matter. Generic n-bit hash preimage search fits this model; collision finding is a different task with different algorithms and trade-offs. Do not apply “halve the bits” to every hash property.

Shor exploits algebraic structure to threaten factoring/discrete-log public-key systems. Grover provides a generic quadratic search improvement. Neither result, by itself, says that a particular deployed system has been broken.

05 / READ THE EXPERIMENT

Read simulation output to understand a circuit

The Qiskit example in the repository will display three different levels of information. They are not different ways of writing the same table: what can be directly obtained in the experiment is the measurement result; the complete amplitude is the "God's perspective" provided by the simulator for learning.

State vector

List the complex amplitudes of the ideal pure state at each ground state. Two qubits require 4 amplitudes, n qubits require 2ⁿ; real devices cannot directly read out the entire vector in one measurement.

Measurement counts

Run the same line several times repeatedly and count the number of occurrences of each classic bit string. 1000 Bell measurements may not be exactly 500 each; first distinguish between finite sampling fluctuations and equipment noise.

Density matrix

Describes pure states and mixed states at the same time, suitable for analyzing noise and decoherence. The calculation basis count of the Bell state can be the same as that of the classical mixed state. Only by changing the measurement basis can we see the difference in coherence.

Compilation and noise

Lines must first be mapped to device-executable gate and connection relationships; gate errors, readout errors, and decoherence will change the distribution. Conclusions for local ideal simulations, noisy simulations and real QPUs should be recorded separately.

Bit order reminder: Bell's derivation on this page is written in |q₀q₁⟩; Qiskit's counts bit strings are usually displayed in classic bit order from high index to low index. If q₀ is measured to c₀ by default, the string 10 means c₁=1, c₀=0. Before comparing hand calculations to the program, write out the measurement mapping.

06 / WHAT ENTANGLEMENT DOES

Entanglement is useful, but it cannot send signals faster than light

The 00 / 11 correlation in the Bell experiment illustrates the relationship between the results, but entanglement cannot be proven based on a single measurement basis alone. To distinguish quantum states from classical correlations, it is necessary to compare correlations under different measurement bases and check experimental assumptions and noise.

TELEPORTATION

Quantum teleportation

The goal is to transfer an unknown quantum state to the recipient, not to move an object. Both parties first share a Bell pair; the sender makes joint measurements and transmits two classic bits; the receiver corrects accordingly. The classic message has not arrived and the receiver cannot restore this state.

SUPERDENSE CODING

Superdense coding

Both parties also share the Bell pair first. The sender encodes the qubit it holds and then sends the qubit; the receiver jointly measures to distinguish the two pieces of classical information. Neither pre-shared entanglement nor the cost of sending qubits can be omitted.

These two protocols show how entanglement can become a communication resource, and also show that "with entanglement, instant communication can be achieved" is a misunderstanding. In security engineering, quantum links, classic authentication and device trust boundaries should be taken into account respectively.

08 / QUANTUM CRYPTOGRAPHY IS DIFFERENT

BB84: It's QKD, not PQC

BB84 uses two sets of incompatible measurement bases to negotiate the original key. Alice randomly selects bits and bases to send the quantum state, and Bob randomly selects the base for measurement; both parties publicize the base selection throughcertified classic channel, retain the position of the matching bases, and then estimate the bit error rate and perform error correction and privacy amplification.

  1. Preparation and measurementRandom bits and random bases; a single measurement cannot copy an unknown quantum state without disturbance.
  2. Filtering and DetectionExpose bases instead of raw bits, discard positions where bases do not match; sample to estimate QBER.
  3. Generate keyIf the bit error rate and security parameters allow, perform privacy amplification after error correction to obtain a shorter key.

Eavesdropping may introduce additional bit errors, but real device noise will also cause bit errors; "if an error is observed, there must be an eavesdropper" is not true. The lack of classic channel authentication leaves the man-in-the-middle problem. QKD requires special quantum communication conditions; PQC is an algorithm running on classical devices, and their deployment prerequisites are different.

09 / LATTICE CRYPTO IN ONE PAGE

Start with a map of lattice cryptography

The lattice is a discrete point set formed by an integer linear combination of a set of basis vectors, which can be written as Λ(B) = {Bz : z ∈ ℤⁿ}. The same lattice may have different bases; two-dimensional drawing can establish geometric intuition, but the real cryptography parameters are high-dimensional and have more stringent structure and distribution requirements.

No noise:b = As mod qWith noise:b = As + e mod q

The core of LWE teaching is: A and b are disclosed, and the secret s is covered by small noise e. If the noise is too small or the dimensionality is too low, the information may be easily recovered; if the noise is too large, the correctness will be destroyed. Security is not only guaranteed by "noise", but also depends on the problem structure, parameters and implementation. Toy LWE in the repository is suitable for observing this trade-off,Does not correspond to the security parameters or implementation of standard algorithms.

ML-KEM · Establish a shared secret

The key encapsulation mechanism specified by FIPS 203, based on difficult issues related to Module-LWE. It solves the key establishment part, authentication still needs to be provided separately by the protocol.

ML-DSA · Verify signatures

The modular digital signature specified by FIPS 204 can be used in signature scenarios such as code and certificates. Signatures have different interfaces and security objectives than KEM and are not interchangeable.

Preserving boundaries: Not all PQCs are lattice cryptography. FIPS 205's SLH-DSA is a hash-based signature. This site explains primitive workflows; lattice mathematics, LWE, attacks and parameter selection are explored in the separate lattice atlas.
