01 / THE MINIMUM MODEL

只需要先掌握四件事

状态与测量

经典位是 0 或 1。单个量子位可写成 α|0⟩ + β|1⟩，其中 |α|² + |β|² = 1。按 0/1 基测量时，只得到一个经典结果：0 的概率是 |α|²，1 的概率是 |β|²。

相位与干涉

振幅可以是复数；只看一次测量概率会遗漏相位。门操作会让不同路径的振幅相加或抵消，这种干涉是算法产生优势的关键，不能理解成“把所有答案一次读出来”。

门与线路

X 类似翻转；H 把 |0⟩ 变成 (|0⟩ + |1⟩)/√2；CX 在控制位为 1 时翻转目标位。线路描述门的顺序，重复测量才能估计结果分布。

工程规模

算法中的可靠逻辑量子位不同于有噪声的物理量子位。能运行一个两量子位实验，并不能推导出已经具备攻击现用 RSA 或 ECC 的机器。

给 x86 / Arm 工程师的类比：把量子线路看成一组作用于状态向量的可逆变换，最后才通过测量取回经典数据。它不像读取寄存器那样随时观察中间态。

03 / ALGORITHM FIELD NOTES

Shor：从模运算周期到因子

Shor 把整数分解归约为求乘法阶 r：使 aʳ ≡ 1 mod N 的最小正整数。先处理容易的经典情况，再选 1<a<N 并计算 gcd(a,N)；若得到非平凡公因子，已完成分解，否则 a 可逆，进入量子求阶。其目标是相对输入位数 log₂N 的多项式复杂度，不是常数时间分解。

为什么阶能揭示因子

If r is even, let x = a^(r/2) mod N. x² − 1 = (x−1)(x+1) ≡ 0 mod N. If x ≠ ±1 mod N, try gcd(x−1,N) and gcd(x+1,N).

N=15、a=2 时，幂依次为 1、2、4、8、1……，r=4 给出 x=4，得到 gcd(3,15)=3、gcd(5,15)=5。奇数阶或平凡半阶幂可能导致本次失败，须更换 a 重试；输出因子必须验证为非平凡因子。ECC 面对的是 Shor 的离散对数算法，不是分解椭圆曲线模数。

量子部分：模乘与相位估计

|0⟩^t |1⟩ → (1/√Q) Σₓ |x⟩ |aˣ mod N⟩, Q=2ᵗ Eigenphases of modular multiplication: k/r, k=0,…,r−1 After inverse QFT and measurement: c/Q ≈ k/r

Hadamard 门产生计数寄存器叠加；受控 U^(2^j) 相干地完成模幂运算。重复平方可提供各幂的经典常数，但模算术本身须用可逆线路实现。工作态 |1⟩ 是多个模乘本征态的叠加，其本征相位为 k/r。逆 QFT 将这种周期相位结构变成计数寄存器的峰值，并非一次读出所有模幂的经典列表。

教材归约通常选择 N² 量级的 Q，以提供足够计数精度。对 c/Q 展开连分数可得到候选分母；若 k 与 r 不互素，分母可能只是 r 的因子，k=0 则不提供阶信息。须检查 aʳ mod N，按需组合或重复采样，再执行因子测试。Q 不整除 r 时，峰值是近似分布。

为什么椭圆曲线密钥同样受影响

对于生成元 P、公开点 Q=dP 的素数阶群，离散对数版本对模群阶 ℓ 的 a、b 相干计算 aP+bQ。输入平移 (−dt,t) 后群元素不变；傅里叶采样提取两个测量频率间的关系，而不是分解有限域模数。

Q = dP; f(a,b) = aP + bQ = (a+bd)P Fourier samples (u,v) satisfy v = d·u (mod ℓ). For u ≠ 0 in this prime-order group: d = v·u⁻¹ mod ℓ.

这是隐藏子群的概念视图；仍需实现可逆群算术、适当寄存器及傅里叶运算。有限域 Diffie–Hellman 也有相应的离散对数形式。

密码学规模攻击还需要容错逻辑量子位、可逆模算术、纠错及庞大门预算。这个例子不是线路执行或性能测试，也不能证明当前硬件已能分解 RSA 密钥。

04 / ALGORITHM FIELD NOTES

Grover：从相位标记到振幅放大

Grover 用可逆判定函数 f(x) 在 N 个候选中标记 M 个可接受解。地址叠加并不会让经典数据库自动具备免费量子访问能力；判定、数据访问和可逆计算都计入成本。它在规定模型下提供 O(√(N/M)) 次 Oracle 查询，相对于经典 O(N/M) 搜索有平方根优势。

U_f|x⟩|b⟩ = |x⟩|b ⊕ f(x)⟩ With |b⟩ = |−⟩, phase kickback gives O_f|x⟩ = (−1)^f(x)|x⟩. D = 2|s⟩⟨s| − I; each amplitude αₓ becomes 2·mean(α) − αₓ.

Oracle 无需预先知道解，也可以检查候选。密钥搜索中，可逆密码线路检验已知明密文对，给匹配密钥施加相位，再反计算清理临时寄存器；有时需要多组明密文对排除其他匹配密钥。直接标记已知答案的教学 Oracle 只演示干涉，没有实现完整密码分析工作负载。

对密码学意味着什么

理想的 b 位密钥唯一解搜索有 N=2ᵇ，查询量约按 2^(b/2) 缩放。这不是实际耗时预测或完整安全估计，还须考虑 Oracle 门数、线路深度、量子存储、并行化与容错成本。一般 n 位哈希原像搜索适用此模型，碰撞搜索则是不同任务，有不同算法及取舍，不能把“位数减半”套到全部哈希性质。

Shor 利用代数结构威胁整数分解/离散对数公钥系统；Grover 提供一般搜索的平方加速。二者都不能单独证明某个已部署系统已经被攻破。

05 / READ THE EXPERIMENT

看懂模拟结果，才算看懂线路

仓库里的 Qiskit 示例会显示三种不同层次的信息。它们不是同一张表的不同写法：实验中能直接拿到的是测量结果；完整振幅是模拟器为学习提供的“上帝视角”。

状态向量 · statevector

列出理想纯态在各基态上的复振幅。两量子位需要 4 个振幅，n 个量子位需要 2ⁿ 个；真实设备不能通过一次测量直接读出整个向量。

计数 · counts

重复运行相同线路若干次，统计每个经典位串出现的次数。1000 次 Bell 测量未必恰好各有 500 次；先区分有限采样波动与设备噪声。

密度矩阵 · density matrix

同时描述纯态与混合态，适合分析噪声和退相干。Bell 态的计算基计数与经典混合态可以相同，换测量基才可能看出相干性的区别。

编译与噪声

线路要先映射到设备可执行的门与连接关系；门误差、读出误差和退相干会改变分布。本地理想模拟、带噪声模拟和真实 QPU 的结论应分别记录。

位序提醒：本页 Bell 推导按 |q₀q₁⟩ 书写；Qiskit 的 counts 位串通常按经典位高索引到低索引显示。若默认把 q₀ 测到 c₀，字符串 10 表示 c₁=1、c₀=0。比较手算与程序前，先写出测量映射。

06 / WHAT ENTANGLEMENT DOES

纠缠有用，但不会超光速传信

Bell 实验中的 00 / 11 相关性说明了结果之间的关系，却不能仅凭单一测量基证明纠缠。要区别量子态与经典相关，需比较不同测量基下的相关性，并检查实验假设与噪声。

TELEPORTATION

隐形传态

目标是把一个未知量子态转移给接收方，不是搬运物体。双方先共享 Bell 对；发送方做联合测量并传送两个经典比特；接收方据此校正。经典消息未到，接收方无法恢复该态。

SUPERDENSE CODING

超密编码

双方也先共享 Bell 对。发送方对自己持有的量子位编码，再把这个量子位送出；接收方联合测量，区分两位经典信息。预共享纠缠与发送量子位的成本都不能省略。

这两种协议展示了纠缠怎样成为通信资源，也说明“有纠缠就能瞬时通信”是误读。安全工程中要分别盘点量子链路、经典认证和设备信任边界。

07 / ALGORITHM MAP

算法名字背后，问题类型各不相同

量子仓库中的线路例子覆盖教学算法与近中期启发式方法。先问“输入承诺是什么、oracle 或电路怎样构造、读出的是什么”，再谈复杂度或密码影响。

算法 / 构件先学什么安全意义与边界
Deutsch–Jozsa干涉、相位与有承诺的函数查询是概念练习；不能直接拿来破解密码。
Groveroracle 标记目标，扩散放大振幅对无结构搜索有平方根级查询优势；实现 oracle 与容错操作仍有成本。
QPE → Shor从受控操作估计相位，再理解阶查找关联 RSA / ECC 的长期公钥威胁；一个 QPE 小例子不等于完整破密。
VQE / QAOA参数化线路、经典优化器与采样反馈适合认识混合工作流；演示结果不代表已获得普遍量子优势。

08 / QUANTUM CRYPTOGRAPHY IS DIFFERENT

BB84：它是 QKD，不是 PQC

BB84 用两组不相容的测量基来协商原始密钥。Alice 随机选比特与基发送量子态，Bob 随机选基测量；双方经已认证的经典信道公开基选择，保留基匹配的位置，再估计误码率并做纠错与隐私放大。

  1. 准备与测量随机比特、随机基；单次测量不能无扰复制未知量子态。
  2. 筛选与检测公开基而非原始比特，丢弃基不匹配的位置；抽样估计 QBER。
  3. 生成密钥若误码率和安全参数允许，纠错后做隐私放大，得到较短的密钥。

窃听可能引入额外误码，但真实设备噪声也会造成误码；“观察到错误就一定有窃听者”不成立。缺少经典信道认证会留下中间人问题。QKD 需要专用量子通信条件；PQC 则是经典设备上运行的算法，两者的部署前提不同。

09 / LATTICE CRYPTO IN ONE PAGE

格密码只先建立一张地图

格是由一组基向量的整数线性组合形成的离散点集，可写作 Λ(B) = {Bz : z ∈ ℤⁿ}。同一个格可能有不同的基；二维画图能建立几何直觉，但真实密码参数是高维且有更严格的结构与分布要求。

无噪声：b = As mod q带噪声：b = As + e mod q

LWE 的教学核心是：公开 A 与 b，秘密 s 被小噪声 e 掩盖。噪声太小或维度太低，信息可能容易恢复；噪声太大又会破坏正确性。安全性并非只由“有噪声”保证，还依赖问题结构、参数与实现。仓库中的 Toy LWE 正适合观察这个权衡，不对应标准算法的安全参数或实现。

ML-KEM · 建立共享秘密

FIPS 203 规定的密钥封装机制，基于 Module-LWE 相关困难问题。它解决密钥建立的一部分，身份认证仍需由协议另行提供。

ML-DSA · 验证签名

FIPS 204 规定的模格数字签名，可用于代码、证书等签名场景。签名与 KEM 的接口和安全目标不同，不能互换。

保留边界：并非所有 PQC 都是格密码。FIPS 205 的 SLH-DSA 属于基于散列的签名。本站详解原语流程；格数学、LWE、攻击与参数选择的深入内容见独立格密码专题。
